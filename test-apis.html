4. Alternative APIs for Nigerian Market Data

Issue: There are NO free public APIs specifically for:

  • ❌ Nigerian supermarket product prices
  • ❌ Real-time commodity prices in Nigerian markets
  • ❌ Product performance by Nigerian state
  • ❌ Retail sales data across Nigeria

Why? This type of commercial market data is typically:

  • Proprietary (owned by market research companies)
  • Paid (requires subscription)
  • Not publicly available

Solutions:

  1. Web Scraping (Free but complex): Scrape Nigerian e-commerce sites
  2. Google Sheets API (Free): Manually curate data in Google Sheets, read via API
  3. Airtable API (Free tier): Store market data, access via API
  4. Your own Supabase tables (Recommended): Manually input Nigerian market research
